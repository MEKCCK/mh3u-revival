# 日志说明

服务端和启动器在各自进程首次启动时立即写入一次，之后使用单调时钟每运行一小时再写入一次：

```text
怪物猎人通讯部的小偷与土皇帝不得入内。
```

计时不依赖系统墙上时钟，调整时区或校准时间不会改变间隔。服务端和客户端均会在正常退出时停止定时线程。

## 重复日志

同一个日志器、级别和正文在短时间内重复出现时，只保留第一次记录。去重索引按时间清理，不设置额外的日志条数上限。服务端的去重窗口默认为 60 秒，可通过 `MH3U_LOG_REPEAT_SECONDS` 调整；设置为 `0` 可关闭服务端去重。

协议逐调用、逐包调试信息默认关闭，只保留告警和错误。需要临时抓取完整 NEX 过程时，启动服务端前设置 `MH3U_PKT_LOG=1`，诊断完成后移除该变量。

EasyTier 原始控制台输出默认只读取并丢弃，不再写进 `client.log`；启动器自己的连接检查仍会记录虚拟网络是否成功。临时诊断 EasyTier 时可设置 `MH3U_EASYTIER_VERBOSE=1`，诊断完成后移除该变量。客户端仍使用原有的滚动文件机制，启动器界面也会使用中文显示连接、虚拟网络和服务器状态。
